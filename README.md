# Eng base

App Android nativo (Kotlin + Jetpack Compose) para estudar Engenharia Civil.

- Plano de estudo diário dividido por matéria e dificuldade
- Tutor de IA que explica, faz testes e resolve cálculos
- Caderno: contas passo a passo, em formato de caderno
- Foco: cronômetro 25 min estudo / 5 min pausa

## Pastas
- `app/` código do aplicativo
- `backend/worker.js` servidor da IA (guarda a chave fora do app)
- `.github/workflows/build-apk.yml` compila o APK e publica em Releases
- `docs/PROJECT_STATUS.md` registro de continuidade

Nenhum segredo fica neste repositório.
